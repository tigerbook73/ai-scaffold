# AI Skills

A local AI skill library that distributes skills to any project with a single `/aisk/sync` command.

## Setup (one-time per machine)

```bash
git clone .../ai-skills ~/code/ai-skills
cd ~/code/ai-skills && npm install && npm run register
```

After this:
- `~/.ai-skills/config.json` records this repository's path
- Global meta-commands (`/aisk/sync`, `/aisk/create-skill`) are installed in `~/.claude/commands/aisk/`

## Using skills in a project

Run the following in any project's Claude Code session:

```
/aisk/sync
```

This syncs all skills to the current project's `.claude/commands/aisk/`.

## Available skills

| Skill | Description |
|-------|-------------|
| `refresh-arch` | Scan the codebase and generate or refresh `.ai-skills/architecture.md` |
| `check-arch` | Check whether code changes align with architecture decisions |
| `prepare-task` | Create a feature/refactor task branch and planning documents |
| `close-task` | Verify task completion and clean up planning documents |

## Adding a new skill

```
/aisk/create-skill path/to/my-skill.md
```

Or have Claude generate one from a description:

```
/aisk/create-skill my-skill
```

After adding, run `git commit` to persist, then use `/aisk/sync` to distribute to projects.

## Repository structure

```
skills/           # skill source files (commands + resources)
claude/
  setting.json    # sync manifest (generated by npm run build)
scripts/
  setup.ts        # global initialization (npm run register)
  sync.ts         # sync implementation (npm run sync)
  build.ts        # generates setting.json (npm run build)
  create-skill.ts # adds a skill (npm run create-skill)
docs/
  OVERVIEW.md     # full design documentation
```
