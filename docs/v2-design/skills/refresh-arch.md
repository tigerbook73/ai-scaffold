# refresh-arch

扫描代码，刷新 architecture.md 的 AI 维护区，保留人工维护区。

**约束**
- [写操作] 只写 `.ai-rules/context/architecture.md`，不修改其他文件
- `<!-- 人工维护区 -->` 注释以下的内容永远不覆盖
- 写入前展示 diff，用户确认后才落盘

**输入**（`$ARGUMENTS`，可选）
- 无参数 → 扫描整个项目
- 路径（如 `src/`）→ 只扫描该目录

**步骤**
1. 读取当前 architecture.md，找到 `---` 后紧跟 `<!-- 人工维护区` 的分界线，保存其后全部内容
2. 扫描代码，提取：
   - 项目概览：从 package.json / README 读取简介、技术栈、常用命令
   - 目录结构：顶层目录树 + 职责推断
   - 典型模式：识别代码中重复出现的结构和通用做法
3. 重写 AI 维护区，拼接保存的人工维护区
4. 展示 diff，等待用户确认
5. 用户确认后写入，更新 `last_updated` 字段
