# AI Skills — Project Overview

## What it is

AI Skills is a **local skill library** that uses Claude Code commands (`.md` files) as its unit of distribution, installing all skills globally with a single `npm run register` command.

Core idea: skills are maintained centrally in a local repository — change once, use everywhere. New skills are promoted to the global library via `/aisk/create-skill`.

---

## Overall Architecture

```
Local skill repository/
├── skills/              ← skill source files
├── claude/setting.json  ← install manifest
└── ...

  ↓ npm run register (new machine, one-time)

~/.ai-skills/config.json          ← records the repository path
~/.claude/commands/aisk/          ← all skill commands, globally available in every project
```

**Two layers:**

| Layer      | Location                                    | Description                              |
| ---------- | ------------------------------------------- | ---------------------------------------- |
| Repository | `{repo}/`                                   | Skill source files, maintained centrally |
| Global     | `~/.ai-skills/`, `~/.claude/commands/aisk/` | Config + all installed skill commands    |

Skills are available immediately in any project after `npm run register`. For a new project, run `/aisk/init-project` to configure `.gitignore` and local permissions.

---

## Repository Directory Structure

```
{repo}/
├── skills/                        ← all skill files, organized by group
│   ├── arch/
│   │   ├── refresh-arch.md
│   │   ├── check-arch.md
│   │   └── README.md
│   ├── create-skill/
│   │   ├── create-skill.md
│   │   └── resource/
│   │       └── skill-format.md   ← read at runtime by create-skill (not copied)
│   ├── init-project/
│   │   └── init-project.md
│   └── task/
│       ├── prepare-task.md
│       ├── close-task.md
│       └── README.md
├── claude/
│   └── setting.json               ← install manifest (command files only, generated by npm run build)
├── scripts/
│   ├── setup.ts                   ← global initialization (one-time)
│   └── build.ts                   ← scan skills/ to generate setting.json
├── package.json
└── docs/
    └── OVERVIEW.md                ← this document
```

> **Tech stack**: All scripts use TypeScript, invoked via `npm run <command>`, executed at runtime by `tsx`, with CLI argument parsing via CAC.

## Per-project Runtime Files

Skills may generate files in the project's `.ai-skills/` directory at runtime. These are **not** installed by `npm run register` — they are created on demand by individual skills:

- `.ai-skills/architecture.md` — written by `/aisk/refresh-arch`, records project-specific architecture decisions

These files should be added to `.gitignore` (handled by `/aisk/init-project`).

## npm Scripts Summary

| Command                | Implementation                                 | Purpose                                                                                            |
| ---------------------- | ---------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `npm run register`     | `scripts/setup.ts`                             | Global initialization (run once on a new machine)                                                  |
| `npm run build`        | `scripts/build.ts`                             | Scan `skills/` and regenerate `claude/setting.json`                                                |
| `npm run create-skill` | `skills/create-skill/resource/create-skill.ts` | Write a skill file to `skills/` and update `setting.json` (usually called by `/aisk/create-skill`) |

> **Runtime dependency**: All scripts are executed as TypeScript via `tsx`; CLI argument parsing uses CAC.

## Management Scripts

### scripts/setup.ts

**Purpose**: Global initialization, run once on a new machine.

**Operations:**

1. Write the current repository path to `~/.ai-skills/config.json`
2. Read `claude/setting.json` and install all skill command files to `~/.claude/commands/aisk/`
3. Remove any stale `.md` files in `~/.claude/commands/aisk/` that are no longer in `setting.json`

**Invocation:**

```bash
npm run register
```

---

### skills/create-skill/resource/create-skill.ts

**Purpose**: Write a skill file to the global repository `skills/` and automatically update `setting.json`.

**Parameters (via CAC):**

```bash
npm run create-skill -- <file> [--name <n>] [--description <desc>] [--force]
```

| Parameter       | Description                                    | Default                                      |
| --------------- | ---------------------------------------------- | -------------------------------------------- |
| `<file>`        | Source file path (required)                    | —                                            |
| `--name`        | Skill name (target filename without `.md`)     | taken from source filename                   |
| `--description` | Skill description                              | taken from the first `#` heading in the file |
| `--force`       | Skip conflict confirmation for duplicate names | false                                        |

**Called indirectly by the `/aisk/create-skill` command**; users do not typically run this directly.

---

### scripts/build.ts

**Purpose**: Scan the `skills/` directory and automatically generate `claude/setting.json`.

**Logic:**

1. Recursively enumerate all `.md` files under `skills/`
2. Skip `README.md` and files in `resource/` subdirectories
3. For each command file, infer `dst` as `.claude/commands/aisk/{filename}`
4. `description`: taken from the first `#` heading; `category`: inferred from directory
5. If the entry already exists in `setting.json`, preserve its existing `description`
6. Write to `claude/setting.json` and output a change summary

**Invocation:**

```bash
npm run build
```

Run after adding or removing files in `skills/`.

## Skill Commands

### /aisk/create-skill

**Invocation**: `/aisk/create-skill <file-path>` or `/aisk/create-skill <skill-name>`

**Effect**: Promotes a skill to the global repository.

**Two input modes:**

| Mode       | Argument form                  | Behavior                                                                                                       |
| ---------- | ------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| File path  | Path to an existing `.md` file | Passed to `create-skill.ts` for processing                                                                     |
| Skill name | Plain name (e.g. `my-skill`)   | Claude generates content from conversation context, writes to `{repo}/skills/{name}.md`, calls `npm run build` |

After execution, manually `git commit` in the ai-skills repository to persist.

**Installation path**: `~/.claude/commands/aisk/create-skill.md` (globally available after `npm run register`)

---

### /aisk/init-project

**Invocation**: `/aisk/init-project` (no arguments)

**Effect**: Configures a new project to work with globally installed aisk skills:

1. Adds `.ai-skills/` to `.gitignore` (with confirmation)
2. Adds `Read(~/.ai-skills/*)` and `Bash(npm --prefix {repo} run *)` to `.claude/settings.json`

**Installation path**: `~/.claude/commands/aisk/init-project.md` (globally available after `npm run register`)

---

## claude/setting.json

The install manifest; describes which skill command files are installed globally.

> Auto-generated via `npm run build`. Contains only command `.md` files — resource files in `*/resource/` subdirectories are excluded.

**Format:**

```json
{
  "version": "1.0",
  "files": [
    {
      "src": "arch/refresh-arch.md",
      "dst": ".claude/commands/aisk/refresh-arch.md",
      "description": "Generate or refresh the architecture decision document",
      "category": "arch"
    }
  ]
}
```

- `src`: source path relative to the `skills/` directory
- `dst`: path relative to `~` where the file is installed
- `category`: skill category (`arch`, `task`, `create-skill`, etc.)

After adding or removing skills, run `npm run build` to regenerate this file, then `npm run register` to apply.

## Typical Workflows

**Initialize on a new machine:**

```
git clone .../ai-skills ~/code/ai-skills
cd ~/code/ai-skills && npm install && npm run register
```

**Configure a new project:**

```
/aisk/init-project
```

**Promote a temporary skill to a global skill:**

```
/aisk/create-skill .claude/commands/aisk/my-experiment.md
# → git commit in the ai-skills repository
# → npm run register to apply globally
```
