# start-walkthrough

Resume a walkthrough from the state file. `resume-walkthrough` is an alias with identical behavior.

**Constraints**
- A `.walkthrough.md` state file must exist with an active record for the current branch
- Context is session-scoped; re-run at the start of each new session to restore walkthrough state

**Steps**
1. Read `.walkthrough.md`; find the record for the current branch.
   - No record found → prompt user to run create-walkthrough first, stop.
2. Validate the state:
   - Groups sourced from design documents → check if the design documents have changed since
     the walkthrough was created; if so, warn that groups may be stale and ask whether to
     continue or rebuild.
   - Groups auto-generated by AI → check if the walkthrough target (e.g., commit range) is
     still valid; if the target no longer exists or has changed significantly, warn and ask
     whether to continue or rebuild.
3. Output a resume summary: walkthrough target, total groups, current group, remaining groups.
4. Present the current group and continue from where it left off.
