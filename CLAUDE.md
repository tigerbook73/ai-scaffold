# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Common Commands

```bash
npm run register                     # One-time setup on a new machine — installs all skills globally
npm run build                        # Scan skills/ and regenerate claude/setting.json
npm run create-skill -- <file>       # Promote a skill file to the global repository
npm run lint                         # ESLint check (scripts/ and skills/*/resource/)
npm run format                       # ESLint --fix (same scope as lint)
```

**After modifying skill files or scripts**: run `npm run lint` before committing.  
**After adding or deleting files in `skills/`**: run `npm run build` to regenerate `claude/setting.json`.

## Architecture

Two-layer structure, data flows in one direction:

```
Local skill repository (this repo)
    ↓ npm run register (new machine, one-time)
~/.ai-skills/config.json             ← stores this repo's path
~/.claude/commands/aisk/             ← all skill commands, globally available in every project
```

Skills are available in any project immediately after `npm run register`. No per-project sync needed.

For a new project, run `/aisk/init-project` to configure `.gitignore` and permissions.

Full design details: `docs/OVERVIEW.md`

## Key Files

- **`claude/setting.json`**: install manifest, auto-generated by `npm run build`. Never manually edit the `dst` field; the `description` field is safe to edit manually and is preserved across builds.
- **`scripts/build.ts`**: scans `skills/`, regenerates `claude/setting.json`.
- **`scripts/setup.ts`**: reads `setting.json`, installs skill commands to `~/.claude/commands/aisk/`, and removes stale global commands.
