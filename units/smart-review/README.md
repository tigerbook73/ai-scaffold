# smart-review

## 干什么的

`smart-review` 用于对指定文件、模块或目录进行迭代式审查和修复。它会先审查目标范围，再修复明确问题，并最多重复三轮，直到没有新问题或达到轮次上限。

该单元适合对局部代码做集中质量检查，例如类型一致性、安全问题、逻辑错误、格式问题或明显遗漏。

## 怎么用

1. 在请求中指定目标路径，例如：`smart-review src/lib/auth`。
2. 可附带审查重点，例如：`smart-review src/lib/auth 专注于类型一致性`。
3. agent 会读取目标范围并识别问题。
4. 对明确问题，agent 会直接在目标范围内修复。
5. 对需要决策或超出目标范围的修改，agent 会暂停并请求确认。
6. 完成后，agent 会汇总修改和剩余风险。

## 组件

- Skill：`skills/smart-review.md`

## 注意事项

- 默认只写入指定目标范围内的文件。
- 可以读取范围外文件作为上下文，但修改范围外文件需要用户明确授权。
- 最多进行三轮审查和修复循环。
