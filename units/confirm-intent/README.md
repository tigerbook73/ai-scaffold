# confirm-intent

## 干什么的

`confirm-intent` 用于在执行任务前确认用户的真实预期。它会总结目标、假设、范围、排除项和下一步操作，并等待用户明确确认后再继续。

该单元适合需求模糊、风险较高、可能产生外部副作用，或用户希望 agent 先澄清再执行的场景。

## 怎么用

1. 在请求中明确提到 `confirm-intent`，或要求 agent 先确认意图。
2. 可以直接附带要澄清的请求，例如：`使用 confirm-intent 澄清这个重构需求：...`。
3. agent 会先推断意图，列出影响结果的假设和实质性歧义。
4. 若仍有关键歧义，agent 会提问并等待回答。
5. 歧义解决后，agent 会给出最终解读；用户明确确认后才执行。

## 组件

- Skill：`skills/confirm-intent.md`

## 注意事项

- 该 skill 只作用于当前请求及其澄清循环。
- 用户明确表示跳过确认或直接执行时，可以跳过最终确认关卡。
- 可用 `exit confirm-intent` 或同等表达停止应用该确认流程。
